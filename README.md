# test_cytoself

## Clone this Repo "test_cytoself"

```code
git clone https://github.com/YanniSchnellbach/test_cytoself.git
```


## How to install

This repo uses `pixi`.
Install with:

```code
curl -fsSL https://pixi.sh/install.sh | sh
````
see documentation for more details: https://pixi.prefix.dev/latest/installation/

## Enter the pixi environment

```code
pixi shell
````


## Test GPU with `python `
```code
python test_GPU.py
```

## Download test dataset

```code
python download_test_data.py
````

## Train model and evaluate 

```code
python test_cytoself.py
````
